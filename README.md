# incubator-telemetry-analysis

Analysis of real telemetry from a queen-bee incubator (see github.com/Mariam-zeqred/queen-bee-incubator). Work in progress; the data is in `data/`:

- `hive-1C5A00_history_2026-10-03.json` — 1 367 readings at 15 s intervals, 3 Oct 2026 (temp, hum, tempOut, humOut, targetTemp, heater, door, cycle fields, ts/iso).
- `heater_stress_log_2026-10-10.csv` — heater endurance test log, one row every 2 minutes.
